Universal Marquee

The ultimate zero-dependency Vanilla JS library for smooth, accessible, infinite scrolling.
Works with text, images, or any custom HTML.

$npm i universal-marquee (coming soon)

Why use it?

Get Started

Initialize with one line of code.

new UniversalMarquee('#my-element', { speed: 50 });

Production Examples

Social Proof

Perfect for client testimonials. Pause on hover enabled.

testimonials.js 
new UniversalMarquee('#demo-testimonials', {
  items: testimonialsData, // Array of objects
  renderItem: (item) => buildCardHTML(item),
  speed: 25,
  gap: '2rem',
  pauseOnHover: true
});

Product Gallery

Showcase angles or collection items. Includes lazy loading skeleton.

gallery.js 
new UniversalMarquee('#demo-products', {
  items: productImages,
  renderItem: (img) => `<img src="${img.src}" ... />`,
  speed: 30,
  gap: '1rem'
});
