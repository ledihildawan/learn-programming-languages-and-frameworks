Universal Marquee

A zero-dependency Vanilla JS library for smooth, accessible, infinite scrolling.
Works with any content. Lightweight. Performance focused.

npm i universal-marquee

Why Use It?

Real-World Examples

Scrolling Testimonials

Build social proof with a smooth, pausable review stream.

main.js 
new UniversalMarquee('#testimonials', {
  items: reviews,
  renderItem: (item) => {
    const el = document.createElement('div');
    el.className = 't-card'; 
    // ... build card html
    return el;
  },
  speed: 30,
  pauseOnHover: true
});

Product Gallery

Showcase images with skeleton loading support.

gallery.js 
new UniversalMarquee('#products', {
  items: productImages,
  gap: '1rem',
  speed: 50,
  renderItem: (img) => `<img src="${img.src}" />`
});
